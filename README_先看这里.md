# 实习申请助手 v0.1

适合 Windows Chrome / Edge。无须安装 Python、Node、购买 API 或提交浏览器商店。

## 安装（约 2 分钟）

1. 把 ZIP 下载到电脑，右键 → 全部解压。不要直接在 ZIP 里面打开。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 打开“开发者模式 / Developer mode”。
4. 点击“加载已解压的扩展程序 / Load unpacked”。
5. 选择包含 `manifest.json` 的 `job-helper` 文件夹。
6. 点浏览器工具栏的拼图图标，把“实习申请助手”固定。
7. 点插件 → “打开岗位列表与设置” → “个人资料与规则”，填好并保存。

## 已预置的可修改条件

- USC / Economics and Data Science
- 预计 2028 年毕业，目标 Summer 2027
- data、analytics、analyst、economics、finance、research、business intelligence、sales 等方向
- 地点不限。请按需要修改这些较宽泛的方向；关键词评分不表示掌握相应技能。
- 姓名、邮箱、电话与工作许可需求未预填。插件不会推断 CPT/OPT、国籍或 sponsorship 答案。

## 平时怎么用

**Handshake：**自己登录，在单个岗位详情页点击插件 → “读取当前岗位并筛选”。支持读取当前网页；暂不支持登录后的后台批量检索。若处于列表与详情混合页面，请进入独立详情页。公司或地点读取为空时，可在工作台手动修正。

**公司官网批量读取：**设置中每行加入 `greenhouse:公司标识`、`lever:公司标识` 或 `lever-eu:公司标识`，保存后点击“读取已配置公司岗位”。公司标识来自其真实招聘页 URL，例如 `https://jobs.lever.co/某个标识` 中的“某个标识”。占位符要替换为真实的英文标识。其他公司招聘系统可用“读取当前岗位”。

**辅助申请：**在招聘网站打开申请表，再点插件 → “填写已保存的基本资料”。检查结果，手动上传简历、填问答与工作许可问题，然后自己提交。网站显示成功后，在工作台标记“已申请”。插件不验证或代替网站的提交结果。

**筛选：**自动打分、排序，显示依据与需要核对的原文。分数不是通过率。公民身份、sponsorship、CPT/OPT、ITAR、毕业时间和学历等用保守的关键词提示，不能据此确定资格，仍需看完整 JD。岗位未提到某条件不等于没有限制。标题不明确为实习时可能被排除，可关闭“仅实习”查看。

**申请进度：**保存 / 准备中 / 已申请 / 面试中 / 已拒绝 / 已放弃；支持备注、去重和岗位 JSON 备份。来源刷新不会清除原有进度，也不会移除已关闭岗位。最近读取时间不代表仍然开放。

## 当前限制

- 自定义下拉框、复杂 Workday 流程、iframe、Shadow DOM、验证码可能需要手工处理。
- 不自动翻到下一页，不自动上传文件，不代答长问答、身份问题或同意条款。
- 网页字段可能在自动填写后被网站重置；请在页面上核对最终值。
- 没有自动投递、后台定时刷新或云端同步。公司批量读取由按钮触发；提交由你完成。
- 尚未在你的 Handshake 登录会话和实际招聘表单中实测。不同网站结构可能需要后续适配。

## 数据

个人资料与岗位放在此浏览器的本地扩展存储中，不是加密的密码库。没有遥测、远程脚本、第三方 AI 或后端服务器。点击填写会把相应资料放入当前网页，网站可能在提交前检测到输入。读取公司公开 API 时会访问对应招聘系统。只在需要处理的招聘页面使用。

导出的 JSON 包含岗位正文、URL、进度与备注，不含个人资料。卸载可能丢失本地记录，请及时导出。不要把密码、证件号码放在备注里。

## 故障排查

- “无法访问页面”：不要在扩展设置页点读取；回到普通招聘网页再点插件。
- Handshake 读到了多个岗位：进入独立详情页重试，或在工作台修正正文。
- 来源 HTTP 404：检查公司标识及 Greenhouse/Lever/Lever EU 类型。
- 没填上：确认已保存邮箱；字段需为空且可见。复杂组件请手填。
- 更新代码后：到扩展管理页点此插件的刷新按钮，再刷新招聘页面。

## 开发和验证

源码随 ZIP 提供，无构建步骤。`node --test tests/*.test.cjs` 运行规则测试和模拟表单测试。`python tests/browser_check.py` 是可选浏览器检查，需要另装 Playwright 与 Chromium；交付环境缺少可启动的浏览器且下载受限，因此该项未能完成。此版本是本地可安装初版，并非已覆盖所有招聘系统的自动申请服务。
