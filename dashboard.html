收集机会，核对资格，把申请一步步推进。

先确认你的资料

已填学校、专业和毕业年份供你核对。姓名、联系方式由你输入；不会推断你的工作许可状态。

筛选规则

公司岗位来源

每行一个公司招聘系统标识。只读取你在此添加的来源；没有预置公司的岗位推荐。

例如官网地址为 https://job-boards.greenhouse.io/某个标识，则输入 greenhouse:某个标识。地址为 https://jobs.lever.co/某个标识，则输入 lever:某个标识。这里只接受字母、数字、下划线和短横线。其他官网用插件读取当前详情。

资料和岗位保存在此浏览器的本地扩展存储中。没有账号、云端同步或 AI API；填表会把对应资料写入你当前打开的网页。导出的 JSON 只含岗位与申请备注，不含个人资料。

从 Handshake 开始

  1. 先在“个人资料与规则”保存基本信息和筛选方向。
  2. 自己登录 Handshake，在独立详情页打开一个岗位。点击浏览器工具栏里的本插件，再点“读取当前岗位并筛选”。
  3. 在岗位列表核对读取到的标题、公司、正文和原文提示。Handshake 未提供结构化数据时，公司与地点可能为空，可在岗位卡片中修正。请不要读取搜索结果页。
  4. 点“打开岗位 / 申请入口”，在网页里进入申请表，再点插件的“填写已保存的基本资料”。
  5. 核对每项内容，自己上传简历、填写问答与工作许可问题，并点击网站提交按钮。看到网站成功提示后，再在这里标记“已申请”。

批量找公司官网岗位

配置 Greenhouse / Lever 公司标识后，点击“读取已配置公司岗位”。每次按需读取并合并、去重，保留原有申请状态和备注。支持 Lever 全球区和欧洲区。暂不支持 Handshake 后台批量搜索、Workday 批量读取、跨域嵌入表单、自动翻页填表或自动上传简历。

如何理解筛选结果

匹配分是标题、年份、方向和地点的规则分数，不是录取概率。毕业范围、学历、年份、工作许可、CPT/OPT、sponsorship、ITAR 只做关键词提示，可能漏检、误判或受否定句影响；“没有提示”不能证明符合条件。每个岗位仍要核对完整原文。当前规则偏向召回，只排除你列出的公司和明显不符合标题规则的岗位；排除项仍可查看。

填写范围

只尝试识别空白的姓名、邮箱、电话、LinkedIn、个人网站、学校、专业等基本字段。不会改已有答案，不会勾选承诺，不会回答工作许可与人口统计问题，也不会点击任何提交按钮。网站的自定义组件可能不接受自动填写，请检查页面上的实际内容。

数据与更新

“最近读取”仅代表获取时间，无法证明岗位仍开放。公司关闭的岗位不会自动删除。导入导出可备份岗位进度；卸载扩展可能清除本地资料。不要在备注里存密码或证件号码。
